# Tree Awareness - Grid Based Webpage

This is a simple yet impactful webpage designed to raise awareness about the importance of trees and the consequences of deforestation. The page uses a **CSS Grid** layout for responsive design, making it user-friendly on all screen sizes. The goal is to educate users about the destructive effects of tree cutting and motivate them to take action.

## Features

- **Responsive Layout**: The page uses CSS Grid for a responsive layout that adapts to various screen sizes, from mobile to desktop.
- **Engaging Visuals**: The site includes visually impactful images, including a chainsaw cutting down trees and a symbolic image showing a tree crying, to illustrate the consequences of deforestation.
- **Clear Call to Action**: The left section of the page provides users with options to navigate through the site, contact the organization, join the cause, donate, and share the message.

## Tech Stack

- **Frontend**:
  - **HTML5** for the structure of the page
  - **CSS3** for styling and responsive grid layout
  - **Images**: Tree and deforestation-related visuals to support the message
